先准备这些人

预先固定 3 位独立审核者，至少 2 位提交实际签名；另需核实参与者实际控制关系与作者身份的外部核验方，以及预先固定的申诉仲裁者。审核可以提出质疑，不要求给出好评。

现有历史 Agent 由同一协调人控制，不能重新贴标签变成多个独立供应商。先做公开报告的真人事实审核；完整付款验收仍需要满足真实身份与作者规则的新任务。

审核者在自己电脑上操作

  1. 安装 Node.js 22.13 或以上版本，下载代码并启动本机页面：

    git clone https://github.com/0xCaptain888/flashfirm.git
cd flashfirm
npm ci
npm run review:console

  2. 打开终端显示的 http://127.0.0.1:端口。点击 Create my local review key 和 Download public key。仅把下载的公钥交给协调人和核验方；密钥文件留在本人电脑。

  3. 公钥固定到计划后，接收公共审核包。通过另一个可信渠道向买方核对计划与买方公钥两个指纹，再点 Validate and open review。

  4. 逐条阅读结论、引用和上下文，填写判断与理由；分别阅读完整/移除样本，填写每项分数与说明。所有判断从空白开始。可以下载草稿，稍后对同一包恢复。

  5. 选择 APPROVE 或 CHALLENGE、说明理由，勾选本人独立完成后点 Sign and download my response。把响应文件发回约定渠道。工具不会向外发请求，也不会创建付款。

审核签名密钥与钱包无关。不要分享 reviewer-key.json、钱包助记词、访问令牌或整个运行目录。

协调人接收签名后

下载精确审核包，分别提供可信指纹。取得至少 2 份真实响应后，用 npm run review:assemble 校验并组装，再向已认证的工作区提交 decision 与 quality。真实身份核验、作者签名、意见冲突、申诉和隐私证明仍会独立检查。

存在不支持的结论或评分冲突时应保留质疑并按政策处理。不能代签、删除不利结果或自动修改评分以放行资金。
